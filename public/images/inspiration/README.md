# Design inspiration photography

Third-party photographs used under the [Unsplash License](https://unsplash.com/license) (free to use, including commercially; attribution not required but given on `/inspiration`). They are **inspiration only** and are never presented as completed JUFAJA projects. Captions and alt text identify them as inspiration photographs.

Each file was downloaded from its Unsplash page, auto-rotated, cover-cropped to 3:2, resized to 1920 × 1280 and encoded as WebP (quality 80, effort 5). Licence and photographer were checked on each photo's page on 18 October 2026. Provenance is mirrored in `src/data/inspiration.ts`, and `tests/hero-gallery.test.js` fails if a file here is missing from that list (or the reverse).
