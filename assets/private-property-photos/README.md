# Private property-photo archive

These 50 original WebP derivatives were moved byte-for-byte from `public/images/projects/` during release-readiness work on 28 October 2026. They must not be served or copied into the public site without documented republication rights from the relevant copyright holder.

The original path, listing provenance and SHA-256 for each file remain in `docs/property-photo-provenance.json`. Original address records remain in `src/data/property-locations.ts` for internal review; public projections withhold their photograph paths. Credit and recorded owner approval are not treated as a photographer licence or proof that JUFAJA constructed a property.

Next.js does not serve this directory as static public content. The originals are retained for owner rights review; no assets were deleted.
